# مطابقة كشف الحساب البنكي مع دفاتر الشركة

أداة ويب في ملف واحد (`index.html`) لمطابقة كشف حساب البنك مع حساب البنك في دفاتر الشركة. تعمل بالكامل داخل المتصفح ولا ترفع أي بيانات.

**التشغيل:** افتح `index.html` في أي متصفح (يحتاج اتصالاً بالإنترنت لتحميل مكتبتي SheetJS و pdf.js).

## المزايا
- رفع عدة ملفات لكل طرف: Excel (`xlsx/xls`) و CSV و PDF نصي.
- اكتشاف تلقائي للأعمدة (تاريخ · بيان · مدين · دائن · مبلغ · مرجع) بعناوين عربية أو إنجليزية، مع إمكانية تعديل الربط يدوياً.
- عكس إشارة الدفاتر تلقائياً (مدين الدفاتر = دائن البنك).
- مطابقة تامة، ومطابقة بفرق أيام مسموح، وهامش تسامح في المبلغ.
- مطابقة مجمّعة: عدة حركات ↔ قيد واحد، في الاتجاهين.
- مطابقة يدوية وفك المطابقة.
- مذكرة تسوية بنكية كاملة عند إدخال الرصيدين.
- تصدير النتائج إلى Excel (أربع أوراق).

## التخصيص
عدّل كائن `BRAND` في أعلى السكربت لإظهار اسمك ورقم التواصل في الرأس والتذييل.
